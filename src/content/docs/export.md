导出任务在后台跑，进度在导出面板里看。导出进行中编辑操作会被暂停，导完继续。

## 视频

| 格式 | 用途 |
|---|---|
| `mp4` | 成片。工程里有字幕数据且字幕显示开启时，会自动烤入字幕 |
| `webm` | VP9 透明视频，可直接叠在别的素材上 |
| `webmfront` | 只含歌词前景层的透明视频 |
| `subwebm` | 只含字幕层的透明视频（需已装载字幕数据且字幕显示开启） |

## 序列帧与分层

| 格式 | 用途 |
|---|---|
| `png` | PNG 序列，打成 zip |
| `pnga` | 带透明通道的 PNG |
| `pngf` | 只有前景层 |
| `pngl` | 分层 PNG，方便在后期软件里单独处理各层 |

## 音频

导出的声音会带上「音频特效」面板里的处理。**变速会改变成片时长**，歌词与节拍随之重排。
详见[功能与手法](../features/) 的「音频特效」。

## 输出位置

桌面版没有浏览器下载目录，导出默认落到：

```
%USERPROFILE%\Videos\JIZURA
```

## 画质

没有单独的画质档位 —— 导出画质由分辨率与帧率决定，编码参数由 FFmpeg 自动选。
分辨率和帧率在设置里改。
