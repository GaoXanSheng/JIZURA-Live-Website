## 两个版本

字面 Live 有两条版本线，装之前先确认自己下的是哪条：

| 版本 | 版本号 | 技术 | 取舍 |
|---|---|---|---|
| **Skia版** | 3.0.0 起 | 渲染与界面全部纯 C# 实现 | 性能更好、改动更新，**不保证稳定性** |
| **CEF版** | 至 2.2.0 | 使用 CEF（Chromium Embedded Framework） | 停在 2.2.0 的旧版线 |

想尝新、要更好的性能，就下 **Skia版**（下载页默认给的就是这条线的最新版）；
想稳一点，去 [Releases 列表](https://github.com/GaoXanSheng/JIZURA-Live/releases) 找 **CEF版** 的 2.2.0。

两条线的界面与用法一致，本文档对两者都适用。

## 1. 载入歌曲

左栏「载入歌曲」选一个本地音频文件；或用「云端音乐」直接搜酷狗 / 网易云。
云端支持载入**我的歌单**（点歌单整单载入，或粘贴歌单链接 / ID 回车载入），VIP 曲目需先在「账号」页扫码登录。

载入后程序会自动分析节拍，并按节拍重排歌词计划。

> 音频、字体、`.jizuralive` 工程包只能通过界面投入，这是有意的设计 —— 应用不接受外部程序传文件路径。

## 2. 写歌词

在歌词面板写入歌词。支持 LRC 时间戳，也支持行内记法：

```
[00:12.00]第一行歌词/这样切分成两段
*强调词*   !闪烁   | 这是注释不显示
[间奏 4]   # 整行注释
```

| 写法 | 含义 |
|---|---|
| `/` | 把一行切成多段 |
| `*…*` | 强调 |
| `!` | 闪烁 |
| `|` | 之后是注释，不显示 |
| `[间奏 N]` | 插入 N 秒间奏行 |
| `#` 开头 | 整行注释 |

带 LRC 时间戳时行时间取自时间戳；没有时按 BPM 推算，也可以手动指定。

## 3. 定风格与手法

右侧面板分几个页签：

- **风格** —— 选整体风格与画幅、配色、字体。
- **手法** —— 十类手法组（layout / enter / hold / exit / decor / treat / bg / cam / fx / trans）逐切分指定，或整组启停。
- **特效 / 输出 / 设置** —— 附加效果、导出参数与程序设置。

不想逐个调，就用**一键随机**整套重抽；已经满意的行和参数可以锁定，随机时保留。

## 4. 对齐时间

用打点同步跟着播放头敲击，快速对齐每行时间；敲错了可以回退重打。
也可以在歌词里直接写 LRC 时间戳，或按 BPM 让程序推算。

## 5. 预览

播放、暂停、定位、循环确认观感。循环可选整首、整行、单个切分，或导出范围。
建议先小步确认再大范围调整，避免一键到底后返工。

## 6. 输出

**直播推流** —— 不导出，直接把画面实时推给 OBS。见[直播推流（Spout）](../spout/)。
这是它最常用的用法：开着编辑器，画面就一直在直播里。

**导出成片** —— 选好格式点导出，进度在导出面板里看。导出进行中其他编辑操作会暂停，
导完继续。支持的格式见[导出格式](../export/)。
