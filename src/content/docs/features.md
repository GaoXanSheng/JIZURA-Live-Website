## 歌词动效

一行歌词可以被切成若干段，每段独立指定手法。写法用 `/` 切分，`*…*` 强调，`!` 闪烁。
没有写切分时，程序按默认规则自动切。

## 27 套风格

整体风格决定配色、质感与动效基调，覆盖从冷峻到明亮的多个方向：

`noir` `crimson` `caution` `magenta` `paper` `hud` `mint` `specimen` `transit` `blueprint`
`rouge` `mono` `hrRuin` `hrNightRec` `hrCurse` `sakura` `ocean` `sunset` `forest` `vapor`
`newsprint` `synth80` `kraft` `candy` `acid` `sumi` `gold`

其中 `hrRuin` / `hrNightRec` / `hrCurse` 是恐怖 / 和風方向的系列。

## 十类手法组

| 组 | 作用 |
|---|---|
| `layout` | 行的版式与排布 |
| `enter` | 入场 |
| `hold` | 持续态 |
| `exit` | 出场 |
| `decor` | 装饰元素 |
| `treat` | 文字处理（描边、纹理等） |
| `bg` | 背景 |
| `cam` | 镜头运动 |
| `fx` | 附加特效 |
| `trans` | 转场 |

每一类下有多套具体手法，可以按整行、按单个切分指定，也可以整组启用 / 禁用。

## 一键随机与锁定

一键随机会把整套观感重抽一遍，省去逐个挑选。已经定下来的行或参数可以先**锁定**，
随机时跳过它们。显式重抽某一行会解除该行锁定，与界面行为一致。

## 打点同步

跟着播放头敲击，把每行歌词的起始时间对上节奏。敲错了回退重打。
这是把一整首歌快速对齐的最省力方式，尤其适合没有现成 LRC 的曲目。

## 云端曲库

在「云端音乐」里搜索酷狗 / 网易云，直接载入曲目或整张歌单。
载入即自动分析节拍并重排计划。

- **酷狗** —— 登录后可用。
- **网易云** —— 扫码登录；VIP 歌曲与完整音质需要登录后才能载入。

登录凭据只保存在**本机服务器**（`config/kg_login.json`、`config/ne_login.json`），不会上传。

## 跟随外部播放器

不想在软件里载入音频，只想让歌词跟着你在别的播放器里放着的歌走 —— 用
「云端音乐 → 跟随播放器 → 开始跟随」。

音频由播放器自己出声，字面 Live 只读系统媒体进度来同步渲染歌词，音频不经过本工具。

- **网易云**需要先在「设置 → 播放和下载」打开「允许在任务栏显示和控制播放」，否则读不到进度。
- 切歌后自动匹配歌词：先按**酷狗（逐字 KRC）** → 再**网易云（逐行）**匹配；
  没匹配上就去「搜索」页手动找。
- 跟随模式下**不要点「载入歌曲」** —— 那会把音频带进来，和外部播放器抢时间轴。
- 打点、切分、字幕等工具照常可用。
- 跟随开启期间本地循环自动停用，停止跟随即恢复。

## 音频特效

「特效」按钮打开音频特效面板，对预览与导出同时生效。

先从上排挑一个预设，或在下方添加效果单元自由组合：

`原声` `音乐厅` `小房间` `现场演出` `宽阔声场` `8D 环绕` `伴唱模式` `夜核加速` `慢速抒情` `复古电台`

- **变速** —— 改变歌曲时长，歌词与节拍自动跟随重排。
- **串联顺序** —— 效果按顺序串联，先后会影响听感，可以调整。
- **导出一致** —— 混响等需要噪声的效果用固定种子，导出与预览逐样本一致。

## 字幕

字幕是独立于歌词动效的一层，在「字幕」面板里配。支持：

- **逐字高亮** —— 已唱 / 未唱双色（KRC 数据）
- **音译行与翻译行** —— 可选，单独控制
- **样式** —— 位置（顶部 / 底部）、字号、描边宽度与颜色、文字颜色、水平与垂直偏移、字体、半透明底条
- **行间保持上一句** —— 空档时不闪掉

字幕只作用于字幕层：预览、独立 Spout 字幕通道、导出烤入，用的是同一份配置。

## 给角色留出位置

直播或竖屏时，角色通常占画面中央。在「设置」页的 **自定义留出画面范围** 里
指定留白位置（中央 / 左 / 右 / 上 / 下）和宽度百分比，文字与演出会自动排到两侧或上下。
预览里用虚线标出留空范围，方便对齐角色。

「导出」页也有一个「留出画面中央」开关，用同一份宽度值。

## 背景与合成

「设置」页的**背景**可以切成 **绿幕** 或 **黑幕**：此时只在单色底上绘制白色文字与演出，
拿到 OBS 或剪辑软件里用色度键 / 滤色合成。常规模式则是风格自带的背景。

背景与「导出」页同源，两处设置的是同一个值。在 OBS 里怎么抠 / 怎么滤，
见[直播推流（Spout）](../spout/) 的「绿幕 / 黑幕与合成」。

## 字体

PV 渲染的字体按这个顺序解析：用户上传 / 本机字体 → 程序旁 `fonts\` 目录与用户字体库 →
系统已装家族 → 按气质（黑体 / 明朝 / 圆体 / 像素 / 书法 / 等宽）落到系统字体 →
逐字兜底 → 微软雅黑保底。

目录与系统都没有的家族，会后台从 Google Fonts 仓库镜像按需拉取完整 TTF 进用户字体库（可在设置页关闭）。
所以同一个工程在不同机器上字形可能不同 —— 缺字体时自动回退，这是预期行为。
